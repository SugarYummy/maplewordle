# Maple Wordle changelog

## alpha v4.3.2 - 23 October 2026
### 🔧 Changes
- **[Audio]** Completely changed all audio files from Mono (64k) to Stereo (128k) or higher.
- **[BGM Clip]** Completely reworked how audio plays to avoid audio peaking.
### 🐛 Fixes
- **[BGM Clip]** Fixed today's [Extreme Mode] audio clip.

## alpha v4.3.1 - 21 October 2026
### 🐛 Fixes
- **[BGM Clip]** Normal Mode not displaying hints properly.
- **[BGM Clip]** You can now type in the [Bonus 2] textbox.

## alpha v4.3 - 21 October 2026
### ✨ New
- **[BGM Clip]** Added Normal Mode, the old BGM Clip is now Extreme Mode.
- **[BGM Clip]** Each mode has its own BGM every day.
- **[BGM Clip]** Normal Mode has longer clips that always start from the beginning, plus hints.
- **[BGM Clip]** Added [Bonus 2]: guess the BGM's title for extra mesos.
- **[BGM Clip]** New 🌈 badge for going all in.
- **[Settings]** The sound button is now a ⚙️ Settings button.
### 🔧 Changes
- **[Mesos]** Reworked meso rewards for BGM Clip.
- **[Mesos]** You now only get mesos for your best mode each day.
- **[Mesos]** Archive days now give a little bit of mesos.
- **[Mesos]** Weekends now give 2x mesos!
### 🐛 Fixes
- **[Boss Wordle]** Gollux's region is now JMS/GMS.

## alpha v4.2 - 20 October 2026
### ✨ New
- **[Shop]** Shop has been added! Cosmetics being added soon!
### 🔧 Changes
- **[General]** New font for the whole site.
- **[General]** Meso numbers are now gold.
- **[General]** Puzzle number, timer and streak now share one info bar.

## alpha v4.1 - 20 October 2026
### ✨ New
- **[Mesos]** Added mesos! Finish puzzles to earn them, fewer guesses = more mesos.

- **[BGM Clip]** Added ⭐ and 💎 badges.
- **[BGM Clip]** BGM Clip has its own volume bar.
